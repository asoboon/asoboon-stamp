## 修正した公開上の問題

1. `manifest.webmanifest` と `sw.js` が参照するアイコンが納品物に存在しなかった
2. READMEに記載された `assets/` と一部資料が実際の納品物と一致していなかった
3. 記録画面だけトロフィー総数が25と表示されていた
4. `localStorage` が利用できない環境では効果音初期化でJavaScriptが停止する可能性があった
5. ゲーム中いつでもミニアプリホームへ戻れる明示的な導線がなかった
