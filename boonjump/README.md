# ブーンジャンプ V2.3.4

Build: `2026-08-07-ranking-dashboard-fast-v12`

## ランキング画面

1. 今日のTOP10
2. 今週のTOP10
3. 歴代TOP10
4. 全8マシンのTOP3

マシンをタップすると、そのマシンの全順位が展開されます。記録ページから登録した場合は、登録したマシンの全順位へ自動移動します。

## 高速化

- ランキング画面の初期取得を11回相当からdashboard API 1回へ統合
- 記録登録前のhealth確認を廃止
- 登録済み名前の再確認通信を廃止
- 初回の名前登録とスコア登録を1回のsubmit通信へ統合
- submit応答の不要な3ランキング再計算をfastモードで省略
- dashboard結果を20秒間メモリキャッシュ

## 必須API

同梱のApps Script API **2.3.4**が必要です。`Code.gs`を全文差し替え、「新バージョン」で再デプロイしてください。
