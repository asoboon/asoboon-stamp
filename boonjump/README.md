# ブーンジャンプ V2.3.6

Build: `2026-08-07-bulk-identity-sync-v14`

## 一括ランキング登録

記録とトロフィー画面から、プレイ済み全マシンの自己ベストを1回の通信で登録できます。

- 初回はランキングネーム入力後、そのまま一括登録
- 最大8台を1通信で送信
- 未プレイ、更新なし、重複は自動判定
- 個別登録ボタンは継続
- 完了後は世界ランキングへ自動移動

## ランキング画面

1. 今日のTOP10
2. 今週のTOP10
3. 歴代TOP10
4. 全8マシンのTOP3

マシンをタップすると、そのマシンの全順位が展開されます。

## 必須API

同梱のApps Script API **2.3.5**が必要です。`Code.gs`を全文差し替え、「新バージョン」で再デプロイしてください。
