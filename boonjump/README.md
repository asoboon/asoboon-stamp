# ブーンジャンプ V2.1.4

Build: `2026-08-06-exhilaration-wheel-v5`

## 3つの操作

1. **アクセル**：実車風タコメーターの針を、車種ごとに異なるレッドゾーンで止める
2. **ターボ**：横に流れるゲージを中央で止める
3. **ニトロ**：飛行中に縦へ流れる丸を、黄色いリングへ重ねてタップする

操作画面では、ボタン以外の広い範囲をタップしても入力できます。判定幅・ゲージ速度・ニトロ丸サイズ・ターゲットサイズはV2.1のゲームバランスを維持しています。

## マシン差

8マシンすべてで、ゲージの速度・動き方・判定幅・ニトロ丸サイズ・ターゲットサイズが異なります。Rは初心者向け、SRは中級者向け、EXR/SSRは成功時の上限が高い上級者向け、SECRETは最難関です。

## ガチャ

- 初回のみ無料かつ未所持マシン確定
- 以後は、1回最後まで飛ぶごとにガチャチケットを1枚獲得
- チケット10枚で10連ガチャ
- 10連の最後の1枠は、未所持の通常マシンが残っていれば未所持確定
- 同じボーナス枠ではSR以上の抽選重みを10倍
- 通常ガチャは10回連続で新車が出なかった場合、次回未所持確定
- 通常7台を集めるとSECRETを解放
