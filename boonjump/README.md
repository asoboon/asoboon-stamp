# ブーンジャンプ V2.1

Build: `2026-08-06-three-action-balance-v1`

## 3つの操作

1. **アクセル**：タコメーターの針を、車種ごとに異なるレッドゾーンで止める
2. **ターボ**：横に流れるゲージを中央で止める
3. **ニトロ**：飛行中に縦へ流れる丸を、黄色いリングへ重ねてタップする

## マシン差

8マシンすべてで、ゲージの速度・動き方・判定幅・ニトロ丸サイズ・ターゲットサイズが異なります。Rは初心者向け、SRは中級者向け、EXR/SSRは成功時の上限が高い上級者向け、SECRETは最難関です。

## ガチャ

- 初回のみ無料かつ未所持マシン確定
- 以後は、1回最後まで飛ぶごとにガチャチケットを1枚獲得
- 10回連続で新車が出なかった場合、次回は未所持マシン確定
- 通常7台を集めるとSECRETを解放
