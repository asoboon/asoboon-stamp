# ブーンジャンプ 永続保存・HOME分離版 v1.1.0

作成日：2026年8月5日  
ビルド：`2026-08-05-persistent-home-v3`

## 公開方法

GitHubの `/boonjump/` フォルダへ、このフォルダの中身をそのまま配置してください。

## 今回の修正

- localStorageの読み込み処理にあった誤参照を修正
- 保存キー `asoboonBooncar.v6` を維持し、既存データを引き継ぎ
- 同じ内容を `asoboonBooncar.v6.backup` にも二重保存
- ガチャ確定時・結果確定時・非表示時・ページ終了時に保存
- 上部の青い「ゲーム」ボタンはブーンジャンプのタイトルへ戻る
- 下部の白い「ミニアプリHOMEへ戻る」は `../home.html` へ移動
- 結果画面のリンク名も「ASOBooNミニアプリHOME」に統一

## 保存される内容

- ベスト記録
- プレイ回数・総飛距離
- 獲得マシン・重複数・チューン
- 各マシンの記録
- トロフィー・達成日時
- PERFECT／TRUEなどの集計
- 効果音設定

端末変更、LINEアプリの削除、LINE側のデータ消去、ドメイン変更ではlocalStorageを引き継げません。
