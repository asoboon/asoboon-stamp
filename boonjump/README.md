# ブーンジャンプ V2.3.2

Build: `2026-08-07-manual-ranking-polish-v10`

## V2.3.2の変更

- ランキングUIを一から整理し、順位・名前・マシン・距離を一列で読みやすく表示
- 上位3位、自分の行、自分の順位カードを明確に強調
- 「今週」「今日」を「今週登録」「今日登録」へ変更し、任意登録方式の意味を明確化
- ランキングネーム欄を折りたたみ式にして、ランキング本体を主役化
- 結果画面に「自動送信されない」ことを明記
- 自己ベストの判定内容・チューンLv・達成時刻を端末に保存し、記録画面から正しい内容で送信
- 歴代ベストを超えなくても、今日または今週の初回登録なら期間ランキングへ登録可能
- 歴代／今週／今日のどれも更新しない記録は `score_log` に追加しない
- 同じ端末の本人確認用 `player_token` を追加
- player_idと登録名が一致する本人は、移行後も自分の名前で弾かれないよう復旧
- 禁止語の短い単語による誤検知を軽減
- V2.3.2専用キャッシュ更新処理を追加
- 車ごとの大幅な操作差、10連ガチャ調整、トロフィー仕様は維持

## ランキング登録の流れ

1. 普通に遊ぶ（名前登録不要）
2. 結果画面または記録画面で登録したい記録を選択
3. 初回だけランキングネームを登録
4. 選んだ記録だけ送信
5. 歴代／今週登録／今日登録の必要なランキングだけ更新

## 必須API

Apps Scriptは同梱の `docs/Code.gs`（API 2.3.2）へ更新し、新バージョンで再デプロイしてください。
