② Apps Script側の準備

  1. app/backend/ASOBooN_PURPLE_GATEWAY_V2_Code.gs を紫専用Apps Scriptへ配置。
  2. Script Properties に AIRWAIT_API_KEY、PURPLE_LINE_MINIAPP_CHANNEL_SECRET、PURPLE_SERVICE_TEMPLATE_NAME、PURPLE_SERVICE_TEMPLATE_PARAMS_JSON を設定。
  3. 紫V2管理用スプレッドシートから setupPurpleGatewayV2() を1回実行。
  4. PURPLE_V2_CONTROL の enabled / workerEnabled / testMode をすべて TRUE にする。
  5. Webアプリとして「自分として実行」「全員がアクセス可」でデプロイし、/exec URLを上へ貼る。
Channel Secret・AirWAIT APIキー・サービス通知トークンは、このページやGitHubへ入力しません。ここに保存するのは公開可能なWeb App URLだけです。
