# ASOBooN STAFF WAIT v0.3

## 修正点
- 受付番号帯による分類を廃止
- Airウェイト `/external/stateless/reservations` の `reservations[].number` をそのまま表示
- `T` / `F` など接頭辞がある場合もそのまま表示
- 10:00 / 12:30 / 15:00 の分類は `waitTypeName` で実施
- 一覧は Airウェイトの受付時間昇順 (`sortStatus=0`, `isDesc=0`) を維持

## 現在まとめる待ち項目
### 10:00
- 10時25分頃入場【土休日特定日】
- 10時ご入場枠【WEB整理券】

### 12:30
- 12時50分頃入場【土休日特定日】
- 12時半ご入場枠【WEB整理券】

### 15:00
- 15時15分頃入場時間【土休日特定日】
- 15時ご入場枠【WEB整理券】

## 注意
GitHub Pages は公開Webです。APIキーをソースコードへ直接書かないでください。
この版では初回に端末ブラウザへ設定を保存します。

呼出・保留・案内の書込みAPI自体は仕様書にありますが、一覧APIは `reserveId` / `version` を返さないため、誤操作防止のためボタンはまだ接続していません。
