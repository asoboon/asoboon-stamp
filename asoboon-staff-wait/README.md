# ASOBooN STAFF WAIT v0.4

Airウェイトの「現在ONになっている入場枠」を自動参照するスタッフ用画面です。

## v0.4 の変更点

- 10:00 / 12:30 / 15:00 の固定設定を廃止
- `外部向け待ち項目取得API` を毎回参照
- `dispFlg=true` の待ち項目を正本として当日の入場枠を自動生成
- 13:30など、その日にだけ有効な枠も自動表示
- WEB枠と店頭枠を自動で同じ回にまとめる
  - 例: `13時半ご入場枠【WEB平日特定日】` + `13時45分から【平日特定日】` → `13:30`
  - 例: `10時ご入場枠【WEB平日特定日】` + `10時15分から【平日特定日】` → `10:00`
- 受付番号は `/external/stateless/reservations` の `number` を無加工で表示
- 予約一覧はAirウェイト側の受付時間昇順を維持
- 100件を超える場合もページングして取得

## 使用API

### 待ち項目取得
POST
`https://cl.airwait.jp/WCLP/api/20160600/external/stateless/wait/type/get`

`dispFlg=true` の待ち項目を現在有効とみなします。
このAPIは `storeId` が必須のため、v0.4では店舗ID（KR〜）を設定してください。

### 受付番号取得
POST
`https://cl.airwait.jp/WCLP/api/external/stateless/reservations`

`sortStatus=0`, `isDesc=0` で受付時間の古い順に取得します。

## 入場回の自動まとめ方

1. 現在ON (`dispFlg=true`) の待ち項目を取得
2. 時刻を含む項目、または「すぐ入場」を対象にする
3. `WEB` を含む待ち項目の時刻をその回の基準時刻にする
4. 店頭用待ち項目がそのWEB時刻の0〜30分後なら同じ回にまとめる
5. WEB枠がない有効項目も独立した枠として表示する

`オレンジパス` と `ご待機者専用` は入場回タブから除外しています。

## 現時点の制約

受付番号一覧APIには `reserveId` / `version` が含まれないため、呼出・保留・案内の書込みボタンは誤操作防止のため無効です。
正式に `reserveId` / `version` を取得できる手段を確定した後に有効化します。
