# ASOBooN LINEミニアプリ：7言語切替（第1段階）

対応言語：ja 日本語 / zh-CN 简体中文 / vi Tiếng Việt / en English / ne नेपाली / ko 한국어 / kmr Kurmancî。
**トルコ語 tr は対象外**。クルマンジー語 kmr はラテン文字を使用する北部クルド語。

## 操作
ホーム・受付・呼出画面上部の「🌐 Language」セレクターをタップして言語を選ぶ。設定は端末内で保存。画面を行き来しても保持。途中で戻しても入力・予約番号は変化しない。

## 対応範囲と安全性
- 初期5言語は400以上の静的キーを整備。韓国語とクルマンジー語は予約・呼出・取消・30分以内の来場・免責等の重要文言を優先して整備。未対応の文言は英語または日本語に戻し、画面上に一部未翻訳であると知らせる（完成翻訳と誤称しない）。
- 受付の予約データ・LIFF・AirWAIT IDやURL・LINE通知処理には一切介入しない。翻訳は表示テキストだけ。辞書または翻訳ランタイムを取得できなくても、日本語の受付は利用可能。
- 免責文言は翻訳と折りたためる日本語原文の両方を表示。言語ごとの最終的な公式翻訳は母語話者・法務確認を推奨。
- その他のページ（カレンダー詳細、料金ページ等）は次段階で多言語化。LINEサービスメッセージも本段階では日本語のまま。

## 表示とキャッシュ
- 呼出状況へ進む横長CTAは金色。通常受付（青）と区別する。金色は呼出済みを意味しない。
- 混雑状況は最大90秒の確認済みデータだけを素早く復元し、約35〜43秒ごとに自動更新。バックエンド側20秒共有キャッシュを維持。古い数字は最新の空きとして表示しない。
- 営業日カレンダーは12時間の表示復元キャッシュを持ち、すべての表示対象日が確認済み・45分以内なら重複通信せず即表示。古ければ表示しながら再取得。同一月の`pageshow`/`focus`による同時リクエストを抑止。
- 本番発行開始：LINE 9:30 / WEB 7:00 のまま。
