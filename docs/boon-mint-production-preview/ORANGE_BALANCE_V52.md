# BOON START ミントソーダ｜オレンジ強化 v5.2（非公開プレビュー）

日付：2026年11月6日

## 変更の結論

前のミントソーダ版はミント／ターコイズの面積が大きく、受付の楽しさが弱く見えていた。
**採用済みの3色は変更せず**、オレンジを「遊びを始める」「人数を追加する」「受付できた」の体験に増やした。

- メイン `#28C7BE`（ターコイズ）
- 背景 `#E3FFF6`（ペールミント）
- CTA・アクセント `#F26F4C`（コーラル）
- 補助の温かい装飾色として `#FFA83F`（みかん色）を少量追加。**主CTAの色や既存パレットの置換ではない。**

## どこを変えたか

1. **ホームのスタートパネル**：右上にオレンジの円形アクセント、READYタグをクリームオレンジに。受付時刻も白で見えるように改善。
2. **WEB受付・案内導線**：左側のコーラルライン、タイマーのアイコンにオレンジ。重要度の低い情報までCTAのようにしない。
3. **利用案内・あそびコンテンツ**：見出しのコーラルライン、遊びのエリアに温かい背景色。ゲーム各種の識別色は残す。
4. **受付の3ステップ**：今のステップは暖色で認識できるまま。選択済み枠の表示を強調。受付可否は既存データ。
5. **人数の＋ボタンと料金**：押せる＋ボタンだけコーラルへ。無効な＋は強調しない。合計金額を暖色ピルで強調。人数・料金は既存公式ロジックの結果を表示するだけ。
6. **受付完了**：チェックをコーラルに、成功パネルに暖色の面を追加。**受付完了は入場可の意味ではない。**
7. **呼出・エラー**：緑GOは正式callingだけ。waitingの前0組は消灯、通信エラー時は以前の受付番号を表示。状態を誤認させるオレンジ装飾は追加していない。
