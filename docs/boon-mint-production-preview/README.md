## なぜ初回読み込みに直接入れなかったか
以前の混雑表示高速化を壊さないため、ミントソーダの約75KBのCSS+JSを「通常HOMEで毎回読む」構成にはしなかった。既存 `build-production.mjs` が生成する本番シェルに**明示的な表示フラグ**を実装。URLで `?boonTheme=mint` が指定された場合だけ、追加デザイン資産をロードする。表示フラグは**ビジュアルレイヤーだけ**で、AirWAITの受付可否を切り替える新機能ではない。

- 通常のHOME：**追加資産なし**、現行表示がそのまま。
- ローカルでの評価：`http://127.0.0.1:4178/home.html?boonTheme=mint`（当該Macでローカルサーバー起動時に限る）。
- 運用上：このプレビューでも既存本番APIに接続可能な構成なので、**手動の実受付操作は禁止**。自動QAはLINE SDKとGatewayをモック化し、外部通信を遮断している。公開後のテストは指定の検証用枠／認証を用いること。
- URLにフラグを付けない通常利用者は従来の画面を利用する。公開を行っていない現状では、このフラグ自体も外部から利用できない。
