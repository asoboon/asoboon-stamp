## 変更内容
採用済みのミント色 `#28C7BE`、ペールミント `#E3FFF6`、パッションオレンジ `#FF7A00` を維持し、以下の場所だけ面積を追加。
- HOME：STARTパネルのオレンジ縁・円形アクセント・あそびコンテンツの暖色面。
- 受付枠：選択済みカードと現在ステップの背景。
- 人数：既存「TODAY'S TEAM」の**右側だけ**オレンジにし、料金は淡い背景＋濃い文字で視認性を確保。子ども人数カードのアクセントも追加。
- 内容確認：実際の料金合計行を淡いオレンジで強調。
- 受付完了：確定済み受付番号を持つ場合のみ暖色の成功カードを表示。

**変更していないもの**：
- AirWAITの正式呼出判定、受付枠／料金／人数制限、通信・予約・キャンセル、LINE通知。
- `waiting` 前0組で緑GO禁止／正式 `calling` のみ緑5灯＋GO。
- 通信エラー・保留・無効ボタンの状態色。
- 公開中のソース、公式LINE・AirWAIT運用設定。

## 適用方法（対象Gitリポジトリで）
