# BOONJUMP v3.2.2 MACHINE SELECTOR REBUILD

## What changed
- Rebuilt the machine-selection screen instead of only restyling the previous garage.
- On portrait phones, each machine is now a full-width BOON RUN-style showcase card.
- Added large vehicle art, rarity, selected state, easy-to-read difficulty, plain Japanese description, one-line strategy tip, BEST, MAX and TUNE.
- Current-machine description on HOME now uses the same plain-language guide.
- Locked cars stay visible and explain how they unlock.

## Plain-language machine guides
- Boon: easy, readable basic timing.
- Wagon: slows near the center and is calm to aim.
- Buggy: looks chaotic but follows the same sequence.
- Bike: one-way meter; no second chance.
- Sport: slow then sudden acceleration.
- Princess: three distinct rhythms.
- Cosmic: fixed warp sequence to memorize.
- Valkyrie: three very short precision windows.
- SECRET: near-perfect triple combo for 5000m-class distance.

## Integrity
- No gameplay balance values changed.
- v3.2.1 PERFECT-100 capture logic retained.
- 25 art VFX assets retained.
