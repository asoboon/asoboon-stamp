【実環境について】
実行環境の管理ポリシーにより、ChromiumからGitHub PagesおよびGoogle Apps Scriptへの実通信ナビゲーションは実行できませんでした。
そのため、Google Apps Script公開URLへのライブ書き込みだけはGitHub公開後の実端末で確認が必要です。
ゲーム側にはrequest_id末尾、端末保存、未送信件数、保存確認結果が表示されるため、通信状態を画面上で判別できます。
Apps Script API 2.2.4と互換で、Code.gsの再更新は不要です。
