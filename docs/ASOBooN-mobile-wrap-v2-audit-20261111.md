# ASOBooN｜スマホ画面の改行不良・再修正 2026-11-11

## 事実
- 前回修正 PR #170 は main にマージされていたが、その直後 GitHub Pages がデプロイ中だったため、旧HOMEのHTMLが引き続き公開されていた。デプロイ完了後の実配信で修正済みアセットに切り替わったことを確認。
- 前回の修正が反映されたコードにも不自然な改行が残存していた。13画面×幅320/375/390/430pxの **52表示条件** を、文字単位の描画座標とスクリーンショットで再調査した結果、語尾が1～2文字だけ次行へ落ちる箇所など **延べ73件** を発見した。
- 修正後、同じ52条件で **不自然な末尾改行0件、横はみ出し0件** を測定した。日本語の自然な文の折り返しをすべて禁止したわけではない。

## 対応
1. HOMEの案内と遊びカードの説明を短文化し、意味のない1文字改行を減らす。
2. 受付の残人数注意文の可読性を向上。320px以下の人数入力カードはラベルと加減算ボタンを上下2段にし、44pxの押下領域を確保。人数・料金・年齢条件と受付処理は不変更。
3. アクセスは駐車場の台数を狭い3列から1列へ。332台、障がい者3台・大型5台などの数量と単位を分離させず、地図5か所・閉鎖情報・一般道18時出庫の情報を保持。
4. 館内ルール見出し、初めての方向け手順、FAQの案内をスマホ向けの短い日本語に整理。安全条件・呼出後30分・受付時間は保持。
5. 変更したホームの短い日本語ラベルには既存の多言語辞書エントリを再利用し、翻訳が日本語に戻ることを抑制。
6. Playwright に狭い画面の末尾1～2文字を検出する回帰テストを追加。
