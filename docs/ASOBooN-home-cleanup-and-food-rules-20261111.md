# ASOBooNミニアプリ｜HOME整理・安全ルール・WEB受付の表示条件（2026-11-11）

## ユーザーからの変更指示
- HOME上の「呼出状況を確認中」の重複をやめる。呼出画面は下部「呼出」タブから使う
- HOMEに「遊べる時間」は残す
- HOMEの常設案内は「営業日カレンダー」「今月のイベント」「初めての方」の3つのみ
- 利用案内・よくある質問・あそびは下部メニューから。FAQは「ご利用案内」内に存在
- 初めての方に保護者見守り・食事全面禁止・飲み物の土足エリア限定を明記
- 館内ルールにもアメ・ガム・お菓子を含めて食べ物の全面禁止を明記
- WEB受付7:00の文言と受付リンクは、WEB枠が空いていると確認できたときだけ表示

## 実装内容
1. HOMEから重複していた料金、アクセス、館内ルール、再入場、遊び5カード、FAQアコーディオンを除外。案内とゲームの各機能自体は下部「ご利用案内」「あそび」から維持。営業日カレンダー・今月のイベントカレンダー・初めての方・タイマーは維持
2. HOMEの待ち情報表示にあった「呼出状況を確認中」の文言を使わず、保存済みの受付番号がある場合は画面下の呼出タブで確認するよう案内
3. WEB受付の表示条件 `hasVerifiedWebReceptionSlot()`：当日営業日、7:00以降、公開フラグtrue、AirWAITと厳密一致のPERSON残人数1以上、取得時刻90秒以内、受付可能時刻、受付ページURL正規確認がすべて揃っているときだけ「WEB受付 7:00」とAIRWAIT受付リンクを表示。未確認/非公開/0/古い/閉館後は表示しない
4. 残人数表自体は残す。0人なら0人として表示する一方、WEB受付リンクは付けず「満員です」と案内する。終了後の人数参照は維持
5. 「初めての方」に次の3注意事項を常設：お子さまから目を離さない／食べ物は一切禁止（アメ・ガム・お菓子含む）／飲み物は土足エリアのみ
6. 館内ルールに飲食専用の注意欄を追加。同じ説明をFAQにも反映
7. 現行の下部メニュー「ホーム／呼出／ご利用案内／あそび」は維持。電話リンクや新設予約ボタンは追加しない

## 安全上の不変条件
- AirWAITの枠公開判定、予約作成、取消、呼出取得・通知、営業区分・料金・混雑予想320人＝100%ロジックは変更しない
- 新しい条件は「受付リンクを見せるための追加の検証」であり、未確認を空きありに読み替えない
- 受付終了後の当日人数・混雑予想の参考表示は引き続き保持
- 新しいWEB受付ページや公式ロゴを作らない
- LINE内iOS/Android実機での予約・通知・取消の操作は現時点未検証
